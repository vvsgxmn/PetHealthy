# 基于SpringBoot+Vue的宠物健康管理系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

PetHealthy 是一款连接宠物主人、兽医与管理员的一站式宠物健康服务平台。随着养宠家庭增加，传统宠物诊疗存在挂号排队繁琐、病历信息分散、疫苗驱虫提醒缺失、药品管理混乱等问题。本系统通过数字化手段，打通宠物全生命周期档案、在线预约挂号、电子病历与处方、健康提醒及科普发布等核心环节。

宠物主人可建立爱宠档案、自主预约兽医、查阅病历与用药信息；兽医可在工作台完成接诊、开具病历与处方；管理员负责用户与兽医账号管理、药品库存监督以及经营数据可视化分析。系统采用 Spring Boot + Vue 前后端分离架构，适合毕设、课设与学习使用。

**适合毕设，课设，学习使用！**

## 主要功能模块

- **用户认证模块**：支持宠物主人、兽医、管理员三类角色登录与路由权限隔离
- **宠物档案模块**：爱宠健康档案建立、成长记录、疫苗与驱虫状态管理
- **预约挂号模块**：兽医科室筛选、医生履历查看、在线时间段挂号
- **诊疗工作台模块**：兽医接诊、电子病历开具、处方用药录入
- **健康提醒模块**：疫苗接种与驱虫日程自动提醒
- **后台管理模块**：用户管理、药品库存、健康科普与 ECharts 经营大盘

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus + JWT + Lombok
- **前端**：Vue 3.5 + Vue Router + Pinia + Element Plus + Vite 5 + ECharts
- **数据库**：MySQL 8.0
